# 定位置メーカー 仮サイト

## 起動方法

```bash
npm install
npm run dev
```

表示されたURLをブラウザで開いてください。

## ファイル構成

- `src/main.jsx`：Reactの起動だけ
- `src/App.jsx`：質問・配置ロジック・画面
- `src/styles.css`：見た目

## 今入っているルール

- 質問に答えるだけで定位置を作成
- 配置理由は表示しない
- 「さ・す・せ」は選ばれたもの同士、選ばれなかったもの同士をセット化
- 「おおえ・おおけ・おおこ」も選ばれたもの同士、選ばれなかったもの同士をセット化
- セットの中身は固定
- 同じ頭文字かつ別セットだけ距離を離す
- 「う」「つ」「し」「も」「ゆ」は上段に置かない
- 囲う7セットは、選んだ左/右の囲い場所に必ず配置
- 結果は縦表記の定位置表
- 軽い広告枠あり

## AdSense対応

最新版では以下を追加しています。

- プライバシーポリシー
- Cookieについて
- お問い合わせ
- このサイトについて
- 利用規約
- 免責事項
- フッターリンク
- 簡易Cookieバナー
- AdSense用広告枠
- `public/ads.txt`
- `public/robots.txt`
- `public/sitemap.xml`
- `ADSENSE_SETUP.md`

本番公開時は、`ADSENSE_SETUP.md` に従ってパブリッシャーID、広告スロットID、サイトURL、連絡先メールアドレスを差し替えてください。
