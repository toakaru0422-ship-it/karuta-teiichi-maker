# 競技かるた定位置メーカー

質問に答えるだけで、競技かるたの自陣定位置案を作成できるサイトです。

公開URL：
https://karuta-teiichi-maker.vercel.app/

## 概要

「む」「め」のどちらが右っぽいか、友札セットのどちらを右に置きたいかなど、直感的な質問に答えていくことで、自陣の定位置案を自動生成します。

初心者の定位置作りや、今の配置を見直すためのたたき台として使うことを想定しています。

配置理由の説明は表示せず、直感で選んで、最後に定位置表がパッと出るシンプルなサイトです。

## 主な機能

* 質問に答えるだけで定位置案を作成
* 一字札や友札セットの左右感を直感的に選択
* セットの中身は固定
* 同じ頭文字かつ別セットの札同士はなるべく距離を離す
* 「う」「つ」「し」「も」「ゆ」は上段に置かない
* 囲い対象7セットは、選んだ左右の囲い場所に必ず配置
* 結果は縦表記の定位置表として表示
* 作成中はボタンに「作成中...」を表示
* プライバシーポリシー、Cookie、お問い合わせ等のページを設置
* Google AdSense用の広告枠を設置

## 定位置生成の基本ルール

### 一字札

以下の質問で、選ばれた札を右下段、選ばれなかった札を左下段に配置します。

* 「む」「め」から1枚選択
* 「さ」「す」「せ」から1〜2枚選択
* 「ふ」「ほ」から1枚選択

「さ」「す」「せ」は、右に選ばれたもの同士、選ばれなかったもの同士をそれぞれセットとして扱います。

### セット固定

質問内でセットとして扱う札は、最終配置でもセットの中身を固定します。

例：

* ちぎりき・ちぎりお
* きみは・きみお
* よのなかよ・よのなかは
* こころあ・こころに
* わたこ・わたや
* なにわが・なにわえ
* あさあ・あさう

### 距離の最適化

同じ文字で始まる札のうち、別セットに属する札同士は、なるべく距離が離れるように配置します。

同じセット内の札同士は、距離を離す対象にしません。

### 上段に置かない札

以下の文字で始まる札は上段に置かないようにしています。

* う
* つ
* し
* も
* ゆ

### 囲い対象の7セット

以下の7セットは、ユーザーが選んだ囲いたい場所に必ず配置します。

* ちぎ：ちぎりき・ちぎりお
* きみ：きみは・きみお
* よの：よのなかよ・よのなかは
* ここ：こころあ・こころに
* わた：わたこ・わたや
* なにわ：なにわが・なにわえ
* あさぼ：あさあ・あさう

## ローカルでの起動方法

```bash
npm install
npm run dev
```

PowerShellで `npm` が実行できない場合は、以下を使います。

```powershell
npm.cmd install
npm.cmd run dev
```

表示されたURLをブラウザで開いてください。

## ビルド

```bash
npm run build
```

## 注意事項

このサイトで生成される定位置案は、競技かるたを楽しむための参考情報です。

特定の配置が勝率向上や競技成績を保証するものではありません。

実際の定位置は、取り方、暗記のしやすさ、身体感覚、所属会や指導者の方針などに応じて調整してください。
